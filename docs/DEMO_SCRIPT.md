# Сценарий демо-видео (1,5–2 минуты)

**Подготовка:** `docker compose up -d`, `seed_demo --reset`, подключённый Telegram-бот, браузер 1440×900, светлая тема, язык RU (для зарубежного портфолио — EN). Запись: OBS / Loom, курсор крупный, без звука уведомлений.
В `.env` поставьте `DEMO_SHOP_CHANGE_INTERVAL=60`, чтобы изменения цен появлялись во время записи.
